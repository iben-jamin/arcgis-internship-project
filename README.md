# arcgis-internship-project


## Overview
Built an interactive ArcGIS StoryMaps project using ArcGIS Online to showcase GIS internship work, including spatial analysis of population and consumer spending trends, polygon feature mapping, ArcPy notebook workflows for geospatial processing and automation, and the development of a public-facing coffee shop map focused on interactive data storytelling and visualization. 


## Objectives
The objective of this project was to apply GIS and data visualization techniques to communicate spatial insights from my internship work through an interactive ArcGIS StoryMap. This project showcases a handful of subprojects I worked on analyzing population and consumer spending patterns, mapping polygon-based geographic features, and developing public-facing web maps that allow users to explore location-based data in a more accessible and visual format.

By connecting geospatial analysis and data science through ArcGIS Online, ArcGIS Pro, StoryMaps, and ArcPy notebook workflows, this project demonstrates how spatial datasets can be organized, analyzed, and presented in a professional and interactive way to better support county planning efforts and public access to geographic information.

## Workflow / Methodology
This project followed a geospatial data analysis workflow, beginning with data preparation and ending with an interactive public-facing StoryMap presentation. Below, you will see the different subprojects I had worked on and how they were incorporated and applied to the workflow / methodology.

### 1. Data Collection & Project Planning
I began by identifying the key datasets and mapping needs for each internship subproject. This included reviewing population-related data, consumer spending information, geographic areas of interest, and local business locations for the coffee shop map.

The Subprojects covered and consisted of: 

- GIS Bridge Analysis 
- Possible Cafe Location
- Fire Station Coverage
- Coffee Map 

### 2. Spatial Data Preparation
Using ArcGIS Pro, I organized and prepared spatial datasets for mapping and analysis. This included managing feature layers, reviewing attribute data, and preparing geographic information for use in ArcGIS Online and StoryMaps.

### 3. Polygon Feature Mapping (Bridge Analysis)
For the Bridge Analysis project, I created polygon-based geographic features gathering data on bridge clearance heights and traffic types across Hamilton County. This project aimed to enhance route planning by identifying areas where mobile clinic vehicles can effectively travel.

### 4. Geospatial Analysis (Possible Cafe)
For the Possible Cafe project, I analyzed location-based patterns related to population and consumer spending trends. Using ArcGIS Business Analyst, I was able to combines map-based analytics with demographic, business, lifestyle, spending, and census data to help make a better informed decision on where would be a better spot for a new cafe in a 15 minute walking distance from my points.

### 5. ArcPy & Notebook Workflows (Fire Station Coverage)
I used ArcPy within notebook workflows to access GIS tools, support geospatial processing, and improve workflow efficiency. This added a more technical and data-focused component to the project beyond manual map creation. Utilizing different strings to paths and feature class functions, I was able to run a buffer analysis and pairwise tool to visualize what areas in Etobicoke, CA would be outside the desired service areas of the nearest fire station. 

### 6. Interactive Map & StoryMap Development
After preparing the maps and spatial layers, I published and organized the content through ArcGIS Online. I then developed an interactive ArcGIS StoryMap to present the internship work in a clear, visual, and accessible format.

### 7. Public-Facing Visualization (Coffee Map)
Being a current student at UTC, I frequently travel to the school and nearby cafes to sit down and enjoy good coffee as well as study. With a desire to find good alternatives outside of the main chains or spots in my area, I decided to create this map to present all of the different options available to those in Hamilton County. The map explores proximity to nearby cafés based on your location, along with the services they provide, their service style (sit-in, drive-thru, or both), the type of establishment (local, regional, or national), and seating availability, ranging from ample to none.
